# Hardware testing

The M0 smoke test requires an fx-CG50 / Graph 90+E: install the generated `CGJRE.g3a` using the device's verified transfer procedure, launch it, confirm the text screen, press EXIT, and confirm safe return to the OS. Record model, OS version, transfer location, observed key behavior, and any crash. This procedure has not been run; the correct transfer location for the target firmware is pending verification.
